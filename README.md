SpillTheStats is a web platform that centralizes League of Legends statistics for players on the LAN server. It offers organized builds and personalized recommendations based on each user's match history.

Developed by **CocoaTeaDevs**: Julián Ramírez Díaz ([Jul1014](https://github.com/Jul1014)) and María Fernanda Cala ([mafecala](https://github.com/mafecala)).
